## 🚀 Featured Project

### 🏠 Los Angeles Airbnb Market Analysis

An end-to-end analytics project analyzing the Los Angeles Airbnb market using **PostgreSQL, SQL, and Power BI**.

The project demonstrates a complete analytical workflow:

**Raw Data → PostgreSQL → Data Validation → SQL Analysis → BI Views → Power BI → Business Insights**

### Key Areas Analyzed

- Executive market overview
- Neighborhood and geographic distribution
- Room-type distribution
- Guest engagement and review activity
- Host activity
- Listing availability
- Monthly availability trends

### Technical Work

- Designed a structured PostgreSQL database from raw Airbnb datasets.
- Performed SQL-based data validation and quality checks.
- Developed business-focused SQL analysis.
- Created reusable SQL views for business intelligence reporting.
- Built a four-page Power BI dashboard.
- Documented methodology, business questions, data definitions, and project limitations.

> **Data limitation:** Pricing analysis was excluded because the source pricing fields contained substantial missing/null values, which prevented reliable pricing analysis.
